# 🌐 ترجمان الذكي | Smart Polyglot Translator

منصة عصرية متكاملة لترجمة النصوص وترجمة الصور الفورية لجميع لغات العالم، مبنية باستخدام **React 19** و **Tailwind CSS v4** ومحرك **Tesseract.js OCR** للتعرف البصري على الحروف.

---

## ✨ المميزات الرئيسية

### 1. 📝 ترجمة النصوص لجميع لغات العالم
- **أكثر من 100 لغة:** دعم شامل (العربية، الإنجليزية، الفرنسية، الألمانية، الإسبانية، التركية، الروسية، الصينية، اليابانية، الأردية، وغيرها الكثير).
- **كشف تلقائي للغة:** يتعرف النظام تلقائياً على لغة النص المدخل.
- **ترجمة فورية ذكية:** ترجمة تلقائية أثناء الكتابة بدون الحاجة للضغط على أزرار (يمكن تعطيلها أو تفعيلها من الإعدادات).
- **إملاء صوتي بالميكروفون (Speech-to-Text):** تحدث بصوتك وسيقوم النظام بكتابة النص فورياً وترجمته.
- **نطق صوتي للترجمة (Text-to-Speech):** استمع إلى نطق الكلمات والجمل بلغات متعددة وبمخارج حروف دقيقة.
- **تبديل اللغات بضغطة زر (Swap Languages):** مع دوران بصري انسيابي.
- **عداد الحروف والكلمات:** إحصائيات فورية للنص المدخل والمترجم.
- **نسخ وتصدير:** نسخ بضغطة زر إلى الحافظة وتنزيل الترجمة كملف نصي `.txt`.

---

### 2. 📷 ترجمة الصور الفورية (OCR & Image Translation)
- **دعم كافة أنواع الصور:** لقطات الشاشة، لوحات الشوارع، قوائم الطعام، وثائق رسمية، أغلفة كتب، إيصالات، وغيرها.
- **طرق إدخال متعددة:**
  1. السحب والإفلات (Drag & Drop) لأي ملف صورة.
  2. الاختيار المباشر من الجهاز أو الهاتف.
  3. **اللصق المباشر من الحافظة (`Ctrl + V`)** لأي لقطة شاشة.
  4. **التقاط مباشر بالكاميرا (Webcam / Mobile Camera)** مع نافذة التقاط تفاعلية.
  5. **نماذج جاهزة للاختبار بنقرة واحدة:** لوحة مطار، قائمة طعام فرنسية، حكمة عربية، اقتباس إسباني.
- **محرك OCR داخلي فائق السرعة:** يعمل داخل المتصفح بنسبة 100% دون إرسال صورك لأي خادم خارجي للحفاظ على الخصوصية التامة.
- **فلتر تحسين التباين والحواف (OCR Boost):** معالجة مسبقة للصور المشوشة أو ضعيفة الإضاءة عبر Canvas لزيادة دقة استخراج الحروف.
- **محرر النصوص المستخرجة:** إمكانية تعديل أي كلمة قرأها المحرك قبل الترجمة أو إعادة ترجمتها بضغطة واحدة.
- **أنماط عرض متعددة:**
  - **عرض جنباً إلى جنب (Split View):** مقارنة الصورة الأصلية والترجمة.
  - **عرض الملصق (Overlay View):** بطاقة ترجمة زجاجية عصرية مدمجة مباشرة فوق الصورة.

---

### 3. 🧠 دعم اختياري للذكاء الاصطناعي (Gemini 1.5 Flash)
- الموقع يعمل مجاناً 100% بدون أي مفاتيح عبر محركات الترجمة الفورية السريعة.
- يمكنك إضافة مفتاح **Google Gemini API** (مجاني) من نافذة الإعدادات لتفعيل:
  - الترجمة السياقية العميقة.
  - تحديد نبرة الترجمة: **(رسمي، ودي / عفوي، أدبي بليغ، أعمال احترافي)**.
  - استخراج إضاءات سياقية وملاحظات لغوية.
  - قراءة وترجمة بصرية فائقة التعقيد للصور.

---

### 4. 🕒 السجل والمفضلة (History & Favorites)
- حفظ تلقائي للترجمات محلياً في المتصفح `localStorage`.
- تمييز الترجمات المفضلة بنجمة ⭐ للرجوع إليها بدون إنترنت.
- بحث سريع داخل السجل وتصفية حسب النصوص أو الصور.
- استعادة أي ترجمة سابقة إلى واجهة العمل بنقرة واحدة.

---

### 5. 🎨 التصميم وتجربة المستخدم (UI/UX)
- **Tailwind CSS v4:** تنسيقات عصرية، تدرجات لونية، تأثيرات زجاجية (Glassmorphism).
- **الوضع الليلي والنهاري (Dark / Light Mode):** مع حفظ تلقائي للتفضيل.
- **خط القاهرة (Cairo Font):** تجربة قراءة عربية أنيقة ومريحة للعين.
- **متوافق مع جميع الشاشات:** الهواتف الذكية، الأجهزة اللوحية، والشاشات العريضة.

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الحزم (إذا لزم الأمر)
npm install

# تشغيل خادم التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build
```

يعمل الخادم تلقائياً على الرابط:
`http://localhost:5173`
